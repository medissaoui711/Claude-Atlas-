# التحقق البرمجي والجودة | Code Verification & Quality

توضح هذه الوثيقة آليات ضمان الجودة والتحقق البرمجي المعتمدة حالياً في مشروع **Claude Atlas**.

---

## 🔍 1. منظومة الفحص الثابت (Static Analysis & Type Checking)

يعتمد المشروع على مترجم **TypeScript 5.8+** كخط دفاع رئيسي لضمان سلامة الشيفرة وصحة تمرير الخصائص بين المكونات والبيانات.

### أمر الفحص البرمجي المعتمد:
```bash
npm run lint
```
هذا الأمر يستدعي:
```bash
tsc --noEmit
```

### ماذا يفحص `tsc --noEmit`؟
1. **مطابقة الواجهات البرمجية**: التحقق من أن كافة الكائنات المعرفة في `src/data/` تطابق حرفياً الواجهات في `src/types.ts`.
2. **صحة مسارات الاستيراد**: كشف أي ملف مفقود أو مسار غير صحيح.
3. **خصائص مكونات React**: التأكد من تمرير كافة الـ Props المطلوبة وعدم وجود خصائص مجهولة أو متعارضة في JSX.
4. **تجنب تراجع الأنواع**: منع محاولات الوصول لخصائص غير موجودة في الكائنات الاختيارية (Nullish checking).

---

## 🏗️ 2. التحقق عبر بناء الإنتاج (Production Build Verification)

```bash
npm run build
```
يقوم محرك **Vite 6** بالتالي:
1. تحويل كافة ملفات TypeScript و JSX إلى كود JavaScript مصغر ومتوافق مع متصفحات الإنتاج.
2. تجميع وتطبيق قواعد **Tailwind CSS v4** والتخلص من الفئات غير المستخدمة (Purge / Tree-shaking).
3. التأكد من معالجة كافة الأصول الثابتة (مثل الصور والأيقونات) وحزمها في مجلد `dist/`.

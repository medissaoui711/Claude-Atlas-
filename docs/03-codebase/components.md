# دليل المكونات التفاعلية | Components Guide

يحتوي مجلد `src/components/` على كافة عناصر واجهة المستخدم المستقلة القابلة لإعادة الاستخدام. تم تصنيف المكونات في مجلدات فرعية وفق مجالات وظائفها:

---

## 1. المكونات المشتركة (`src/components/common/`)

| المكون | الملف | الوصف والمسؤولية |
| :--- | :--- | :--- |
| **`Navbar`** | `Navbar.tsx` | شريط التنقل العلوي، يحتوي على شعار المنصة، روابط الواجهات، زر البحث السريع، مبدل اللغة، وزر فتح المسار الشخصي. |
| **`Footer`** | `Footer.tsx` | تذييل الصفحة، يتضمن حقوق المشروع، روابط خارجية، وروابط سريعة لأهم الأقسام. |
| **`MobileBottomNav`** | `MobileBottomNav.tsx` | شريط التنقل السفلي للأجهزة المحمولة والشاشات الصغيرة لتحقيق أفضل تجربة إبهام (Thumb-friendly UX). |
| **`CommandPalette`** | `CommandPalette.tsx` | لوحة أوامر حوارية تفتح باختصار `Cmd+K` أو `Ctrl+K`، توفر بحثاً فورياً وتنقلاً مباشراً لجميع العقد والأوامر. |
| **`MyPathDrawer`** | `MyPathDrawer.tsx` | لوح جانبي منزلق يعرض قائمة العقد والمفاهيم المحفوظة في مسار المستخدم، مع نسبة التقدم وإمكانية الحذف السريع. |
| **`Toast`** | `Toast.tsx` | نافذة تنبيه عائمة منبثقة عند القيام بإجراء (مثل إضافة للمفضلة، نسخ كود، إكمال وحدة). |

---

## 2. مكونات الخريطة البصرية (`src/components/map/`)

| المكون | الوصف |
| :--- | :--- |
| **`ArchitectureMap.tsx`** | المحرك البصري الأساسي للخريطة التفاعلية المبني بـ SVG. يرسم العقد والعلاقات ويدعم التكبير والتحريك والتحديد. |
| **`MapControls.tsx`** | أزرار التحكم بالخريطة (تكبير، تصغير، إعادة ضبط المركز، وتصفية المستويات). |
| **`CapabilityDetailDrawer.tsx`** | درج جانبي منزلق يفتح عند النقر على أي عقدة بالخريطة لعرض ملخص فوري أو فتح الدرس الكامل. |

---

## 3. مكونات الدروس والاختبارات (`src/components/lessons/`)

| المكون | الوصف |
| :--- | :--- |
| **`LessonViewer.tsx`** | عارض الدرس الشامل الذي ينسق النقاط الـ 14 للمفهوم بصرياً مع تبويبات واضحة. |
| **`InteractiveExercise.tsx`** | صندوق التمرين التفاعلي الذي يعرض المسألة للمطور، مع أزرار لإظهار التلميحات التدريجية والحل النموذجي. |
| **`QuizModal.tsx`** | نافذة الاختبار الفوري متعدد الخيارات للتحقق من استيعاب المفهوم وتحديث حالة الإكمال تلقائياً. |

---

## 4. مكونات المحاكاة التفاعلية (`src/components/simulations/`)

| المكون | الوصف |
| :--- | :--- |
| **`SubagentsSandboxSimulator.tsx`** | بيئة محاكاة تفاعلية لحقن المهام الفرعية للوكلاء، تتيح اختيار الأدوات المتاحة ومشاهدة عزل السياق والتنفيذ المتوازي وتلخيص النتائج. |
| **`HooksLifecycleTimeline.tsx`** | خط زمني تفاعلي يحاكي مراحل اعتراض الأحداث أثناء تشغيل أدوات الوكيل (Pre, Gate, Exec, Post, Error). |

---

## 5. مكونات المقارنات (`src/components/comparisons/`)

| المكون | الوصف |
| :--- | :--- |
| **`ArchitectureComparisons.tsx`** | جداول مفاضلة معمارية مفصلة بين الأدوات المتقاربة (مثل `CLAUDE.md vs Memory Bank`). |
| **`ScenarioRecommender.tsx`** | أداة توصية تفاعلية تسأل المستخدم عن طبيعة مشروعه لترشيح الأداة المعمارية الأنسب له. |

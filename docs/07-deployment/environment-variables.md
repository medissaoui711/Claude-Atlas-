# متغيرات البيئة | Environment Variables

توثق هذه الوثيقة متغيرات البيئة المعرفة في المشروع وفق ملف `.env.example`.

---

## 🔒 1. المتغيرات المعرفة في `.env.example`

| المتغير | الأهمية | الوصف وطريقة الحقن |
| :--- | :--- | :--- |
| `GEMINI_API_KEY` | اختياري (Optional) | مفتاح استدعاء واجهة برمجة تطبيقات Gemini AI إذا تطلب الأمر ميزات ذكاء اصطناعي إضافية. يتم حقنه تلقائياً في بيئة AI Studio من لوحة Secrets. |
| `APP_URL` | اختياري (Optional) | عنوان URL الكامل الذي يستضيف التطبيق في بيئة Cloud Run. يفيد في الروابط المرجعية الذاتية وتكوينات النشر. |

---

## ⚠️ 2. قواعد الأمان لمتغيرات البيئة
1. **ممنوع الالتزام بملفات `.env` الحقيقية**: لا تقم برفع أي ملف يحمل مفاتيح حقيقية في مستودع Git (تم تضمين `.env` تلقائياً في `.gitignore`).
2. **استخدام `.env.example`**: أي متغير بيئي جديد يتم إضافته في المشروع يجب توثيقه في `.env.example` بقيمة فارغة أو نموذجية.
3. **متغيرات المتصفح**: المتغيرات التي تبدأ بـ `VITE_` فقط هي التي يتعرف عليها متصفح الويب أثناء البناء.

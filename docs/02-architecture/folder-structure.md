# تفكيك هيكل المجلدات | Folder Structure Breakdown

يقدم هذا الدليل شرحاً تفصيلياً للبنية الفعلية لشجرة ملفات ومجلدات مشروع **Claude Atlas**، مع تحديد المسؤولية المعمارية لكل مجلد.

---

## 2. جدول مسؤوليات المجلدات

| المجلد | المسؤولية المعمارية | الممنوعات داخل المجلد |
| :--- | :--- | :--- |
| `src/data/` | تخزين كائنات البيانات كـ TypeScript Modules نقية. | لا يجوز وضع عناصر JSX أو React Hooks داخل هذا المجلد. |
| `src/context/` | إدارة وتوزيع الحالة العالمية ومزامنة `localStorage`. | لا يجوز وضع منطق عرض وتنسيق بصري معقد هنا. |
| `src/views/` | تجميع المكونات لبناء الشاشات الكاملة (Screens). | لا يتم وضع منطق تكراري؛ يتم استخراج العناصر إلى `src/components/`. |
| `src/components/` | مكونات قابلة لإعادة الاستخدام في واجهات متعددة. | تجنب تعديل الحالة العامة مباشرة إلا عبر دوال Context الممررة. |
| `src/types.ts` | مصدر الحقيقة الموحد للأنواع والواجهات (Types & Interfaces). | لا يحتوي على أي كود تنفيذي (فقط types, interfaces, enums). |

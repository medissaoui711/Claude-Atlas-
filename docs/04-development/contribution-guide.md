# إرشادات المساهمة في المشروع | Contribution Guide

نرحب بمساهمات المطورين والمهندسين في إثراء وتطوير **أطلس كلود**. يرجى اتباع الإرشادات التالية لضمان سلاسة وسرعة مراجعة ودمج المساهمات.

---

## 🤝 1. مجالات المساهمة المفتوحة
- **إثراء الدروس والمفاهيم المعمارية**: إضافة نقاط معرفية، تمارين تطبيقية، أو أمثلة شيفرة لملف `src/data/capabilitiesEnrichment.ts`.
- **إضافة أوامر أو كتيبات تشغيل جديدة**: توثيق أوامر وسيناريوهات جديدة في `src/data/commands.ts` أو `playbooks.ts`.
- **تحسينات واجهة وتجربة المستخدم (UI/UX)**: تحسين إمكانية الوصول، الرسوميات المتحركة، أو دعم شاشات إضافية.
- **تحديث التوثيق الهندسي**: سد أي فجوات توثيقية في مجلد `docs/`.

---

## 📝 2. خطوات تقديم مساهمة (Pull Request Process)

1. **التفرع (Fork & Branch)**:
   - قم بعمل Fork للمستودع ثم أنشئ فرعاً جديداً لمهمتك:
   ```bash
   git checkout -b feature/enrich-hooks-lesson
   ```

2. **كتابة التعديل والالتزام بالمعايير**:
   - التزم بالمعايير الموثقة في [المعايير البرمجية](./coding-standards.md).
   - إذا قمت بتغيير في الواجهات، تأكد من مراعاة اللغتين العربية والإنجليزية.

3. **الفحص المحلي الإلزامي**:
   - شغّل فحص الأنواع والبناء للتأكد من خلو المشروع من أي كسر:
   ```bash
   npm run lint
   npm run build
   ```

4. **إرسال طلب الدمج (Open PR)**:
   - افتح Pull Request جديد مستخدماً القالب المعياري في المستودع (`.github/PULL_REQUEST_TEMPLATE.md`).
   - اذكر بوضوح التغييرات التي قمت بها والمشاكل التي يعالجها الطلب.

# سجل القرارات المعمارية | Architecture Decision Records (ADR)

## 📌 ما هو سجل ADR؟
سجل القرارات المعمارية (Architecture Decision Record) هو وثيقة ملخصة تصف قراراً معمارياً مهماً تم اتخاذه في المشروع، متضمناً السياق، الخيارات البديلة التي تمت دراستها، والنتائج الإيجابية والسلبية للقرار.

## ✍️ كيفية إضافة قرار معماري جديد
1. انسخ ملف القالب `docs/adr/0001-template.md`.
2. أنشئ ملفاً جديداً برقم تسلسلي تالٍ (مثال: `0005-your-decision-title.md`).
3. املأ الأقسام بعناية (السياق، القرار، البدائل، والآثار).
4. أضف القرار إلى جدول الفهرس أعلاه وافتح Pull Request للمراجعة.

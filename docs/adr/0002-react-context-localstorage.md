# ADR-0002: اعتماد React Context API مع LocalStorage لإدارة الحالة

## الحالة (Status)
معتمد (Accepted)

## التاريخ (Date)
2026-09-19

## السياق (Context)
يحتاج تطبيق **Claude Atlas** إلى إدارة حالة تشمل:
- الواجهة النشطة والتنقل.
- العقد المحددة وعمليات التصفية والبحث.
- المسار التعليمي المخصص للمستخدم، المفضلة، ونسبة الإنجاز.
- تفضيلات اللغة والسمة.
مع الحاجة إلى بقاء بيانات المستخدم محفوظة بين الجلسات دون إجباره على تسجيل الدخول أو الاعتماد على خادم خارجي.

## القرار (Decision)
اعتماد **React Context API** المخصص عبر `AppContext.tsx` كطبقة إدارة حالة مركزية وحيدة، مقترنة بمزامنة فورية وذرية مع **`localStorage`** في المتصفح باستخدام المفاتيح ذات البادئة `cfw_`.

## البدائل التي درست (Alternatives)
1. **Redux Toolkit**:
   - *سبب الاستبعاد*: إضافة تعقيد معماري وحجم زائد للحزمة البرمجية (Boilerplate) لا يتناسب مع طبيعة التطبيق كأطلس تصفح وتعلم خفيف.
2. **Zustand / Jotai**:
   - *سبب الاستبعاد*: مكتبات ممتازة، ولكن React Context الأصلي كافٍ تماماً دون الحاجة لإضافة اعتماديات خارجية إضافية في `package.json`.
3. **قاعدة بيانات سحابية (Firebase / Supabase)**:
   - *سبب الاستبعاد*: تتطلب شاشات تسجيل دخول، اتصالاً بالإنترنت، وتزيد من مخاطر الخصوصية وكلفة البنية التحتية.

## التبعات (Consequences)
- **الإيجابيات**:
  - صفر اعتماديات خارجية لإدارة الحالة.
  - خصوصية تامة؛ بيانات المستخدم لا تغادر جهازه أبداً.
  - سرعة استجابة فورية وتوافق كامل مع بيئات الـ iFrame و WebView.
- **السلبيات**:
  - عدم مزامنة البيانات تلقائياً بين أجهزة متعددة لنفس المستخدم (يمكن معالجتها مستقبلاً عبر تصدير/استيراد ملف JSON).

# مصادر الحقيقة الموحدة | Sources of Truth Matrix

لمنع ظاهرة تآكل التوثيق والشيفرة (Documentation & Code Drift)، يحدد هذا الجدول بوضوح **المصدر الوحيد للحقيقة (Single Source of Truth - SSOT)** لكل نوع من البيانات والمعلومات في المشروع.

---

## 🧭 مصفوفة مصادر الحقيقة

| نوع المعلومة | مصدر الحقيقة المعتمد (SSOT) | الملاحظات والمسار |
| :--- | :--- | :--- |
| **قائمة التبعيات والإصدارات والأوامر النصية** | `package.json` | أي حزمة أو أمر نصي يجب أن يُعرّف هنا أولاً. |
| **الأنواع والواجهات البرمجية (Types & Interfaces)** | `src/types.ts` | كافة الكائنات والبيانات تخضع للتعريفات المكتوبة هنا حصرياً. |
| **العقد المعمارية والتصنيفات الأساسية** | `src/data/capabilities.ts` & `categories.ts` | قائمة المفاهيم ومستوياتها وعلاقاتها. |
| **محتوى الدروس والتمارين المعيارية** | `src/data/capabilitiesEnrichment.ts` | النصوص الكاملة للدروس والتمارين وحلولها واختباراتها. |
| **أوامر Claude Code وكتيبات التشغيل** | `src/data/commands.ts` & `playbooks.ts` | تفاصيل أوامر الطرفية وسيناريوهات العمل. |
| **قوالب ملفات التكوين والمهارات** | `src/data/templates.ts` | القوالب التأسيسية لـ `CLAUDE.md` ومواصفات الوكلاء. |
| **الحالة اللحظية للتطبيق** | `src/context/AppContext.tsx` | الحالة الحية أثناء تشغيل التطبيق في المتصفح. |
| **بيانات المستخدم الشخصية وإنجازه** | `localStorage` | المفاتيح المسبوقة بـ `cfw_` داخل متصفح المستخدم. |
| **متغيرات البيئة المسموحة** | `.env.example` | يوثق كافة مفاتيح البيئة الصالحة للمشروع. |
| **إعدادات البناء والتجميع والـ Aliases** | `vite.config.ts` | إعدادات المترجم والمسارات المستعارة ومكونات Vite. |
| **إعدادات ومسارات CI/CD** | `.github/workflows/ci.yml` | بيئة وإجراءات الفحص التلقائي على GitHub. |
| **القرارات المعمارية التاريخية** | `docs/adr/` | أسباب اتخاذ القرارات المعمارية الرئيسية وتاريخها. |

# سجل الدين التقني والتحسينات المستقبلية | Technical Debt & Roadmap

تطبيقاً لمبدأ النزاهة الهندسية وعدم إخفاء الفجوات، يوثق هذا السجل مجالات التحسين والدين التقني المسجلة حالياً في كود **Claude Atlas**.

---

## 📌 1. الفجوات التقنية المسجلة (Recorded Technical Debt)

| المعرّف | البند | الأثر الحالي | خطة المعالجة المقترحة | الأولوية |
| :--- | :--- | :--- | :--- | :--- |
| **TD-01** | غياب الاختبارات الآلية (No Unit/Component Tests) | **[تم الإنجاز والاعتماد ✅]** تم إعداد Vitest و React Testing Library مع اختبارات الوحدات والمكونات ونظام التغطية والتكامل في CI. | تمت المعالجة الكاملة. | **منجز (Resolved)** |
| **TD-02** | حجم ملفات البيانات في حزمة التحميل الأولي | تحميل كافة بيانات الدروس والكتيبات في حزمة JS واحدة قد يؤثر على سرعة التحميل الأولية البطيئة في الشبكات الضعيفة. | تطبيق الاستيراد الديناميكي (Dynamic Imports / Code Splitting) لبيانات الإثراء المعرفي المتقدمة عند الحاجة فقط. | **متوسطة** |
| **TD-03** | خادم Express غير نشط في الحزمة الأساسية | وجود `express` و `@types/express` في `package.json` مع أن التطبيق يعمل كـ SPA بالكامل عبر Vite. | الإبقاء عليه للبيئات التي تتطلب تشغيل خادم مخصص (Fullstack mode)، أو تنظيف التبعية إذا تقرر الاعتماد حصرياً على الاستضافة الثابتة. | **منخفضة** |
| **TD-04** | مزامنة التخزين السحابي للمسار الشخصي (Cloud Sync) | بيانات التقدم تحفظ في `localStorage` لجهاز واحد فقط وتفقد عند مسح الكاش أو التبديل لجهاز آخر. | إتاحة تصدير واستيراد مسار التعلم بصيغة JSON، أو دعم خيار Firebase Firestore اختياري لمن يرغب بالمزامنة عبر الأجهزة. | **متوسطة** |

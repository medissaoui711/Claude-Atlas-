# مسرد المصطلحات المعمارية | Architectural Terminology

يحتوي هذا المسرد على التعريفات الموحدة والمصطلحات التقنية المستخدمة في **Claude Atlas** ومنظومة **Claude Code** لضمان تطابق الفهم لدى جميع المساهمين والمطورين.

---

| المصطلح بالإنجليزية | المصطلح المعرّب | التعريف والدور المعماري |
| :--- | :--- | :--- |
| **`CLAUDE.md`** | ملف الدستور والتوجيهات | ملف Markdown يوضع في جذر المشروع ليعمل كـ "دستور" للوكيل، يحدد أنماط الشيفرة، أوامر البناء والاختبار، والقيود الصارمة. |
| **Memory Bank** | بنك الذاكرة التراكمية | نظام مجلدات وملفات يحفظ فيه الوكيل القرارات المعمارية وسياق التغييرات التراكمي عبر جلسات العمل المتعددة. |
| **Subagents** | الوكلاء الفرعيون المستقلون | مسارات عمل معزولة السياق يُطلقها الوكيل الرئيسي لإنجاز مهمة فرعية محددة (مثل فحص ثغرة، استكشاف كود، تشغيل اختبارات) وإرجاع الخلاصة دون تلويث نافذة السياق الأساسية. |
| **Lifecycle Hooks** | خطافات دورة الحياة | آليات برمجية وأوامر نصية يتم اعتراضها تلقائياً قبل (`Pre-Tool`) أو بعد (`Post-Tool`) تنفيذ أدوات الوكيل للتحقق الأمني أو التوثيق التلقائي. |
| **MCP (Model Context Protocol)** | بروتوكول السياق النموذجي | بروتوكول مفتوح المصدر يربط نماذج الذكاء الاصطناعي بمصادر البيانات الخارجية وأدوات التطوير (مثل GitHub, Postgres, Jira) بصيغة Client-Server موحدة. |
| **Skills (`SKILL.md`)** | المهارات المتخصصة | حزم تعليمات وقواعد متخصصة توجه الوكيل لكيفية التعامل مع مكتبة أو تقنية بعينها (مثل مهارة Tailwind v4 أو مهارة Drizzle ORM). |
| **Slash Commands** | الأوامر المائلة الطرفية | أوامر مسبقة الإعداد تبدأ برمز `/` وتنفذ إجراءات سريعة وموجهة في بيئة الطرفية (Terminal). |
| **Playbooks** | كتيبات التشغيل المعيارية | وصفات إجرائية متسلسلة خطوة بخطوة للتعامل مع سيناريوهات معقدة (مثل هجرة مشروع، تدقيق أمني شامل). |
| **Context Window** | نافذة السياق | الحد الأقصى من الرموز (Tokens) التي يستطيع النموذج معالجتها في الجلسة الواحدة. |
| **Single Source of Truth (SSOT)** | مصدر الحقيقة الموحد | مبدأ معماري يقضي بأن تكون كل معلومة مخزنة ومُعرّفة في مكان واحد فقط داخل الشيفرة دون تكرار. |
| **Capability Node** | عقدة قدرة معمارية | الكائن البرمجي الأساسي في الأطلس الذي يمثل مفهوماً تقنياً في المنظومة ويحمل بيانات النموذج المعياري ذي الـ 14 نقطة. |

# نطاق المشروع والحدود التشغيلية | Project Scope

تحدد هذه الوثيقة بوضوح ما يدخل ضمن نطاق تطبيق **Claude Atlas**، وما يقع عمداً خارج نطاقه، لتفادي تشتت المطورين وتوجيه جهود التوسع المستقبلي.

---

## 🟢 1. ما يدخل في النطاق (In Scope)

### 1.1 الواجهات التفاعلية الـ 10
التطبيق يحتوي حالياً على 10 واجهات وظيفية مكتملة:
1. **الرئيسية (`HomeView`)**: واجهة الهبوط والتعريف بمركز المنظومة واستعراض الإحصائيات والأقسام.
2. **الخريطة الكاملة (`FullMapView`)**: خريطة بصرية تفاعلية مدعومة بـ SVG لعرض العقد المعمارية والترابطات مع فلاتر البحث والمستويات.
3. **مستكشف القدرات (`CapabilityView`)**: استعراض مفصل للعقد التقنية وتطبيق فلاتر التصنيف والمستويات.
4. **مركز الدروس والتعلم (`LearnView`)**: تفاصيل العقد المعمارية عبر النموذج المعياري ذي الـ 14 نقطة مع التمارين التفاعلية والاختبارات.
5. **المسارات التعليمية (`LearningPathsView`)**: مسارات تعليمية موجهة للمبتدئين والمتوسطين والخبراء.
6. **دليل الأوامر (`CommandsView`)**: موسوعة أوامر Claude Code الطرفية مع معايير الاستخدام والبارامترات.
7. **كتيبات التشغيل (`PlaybooksView`)**: أدلة خطوة بخطوة لمهام هندسية متقدمة (مثل إعداد بيئة مونو-ريبو، التدقيق الأمني، وهندسة البرومبت).
8. **مولدات القوالب (`GeneratorsView`)**: أدوات توليد ملفات `CLAUDE.md` والمهارات والوكلاء مع محرر ومعاينة فورية وتصدير.
9. **مختبر الأوامر والبرومبت (`PromptLabView`)**: نماذج وأمثلة لأوامر Claude Code المتقدمة في سيناريوهات برمجية حقيقية.
10. **لوحة التحكم والمتابعة (`DashboardView`)**: نظرة شاملة على تقدم المستخدم، الإحصائيات، المفاهيم المفضلة، ونسبة إنجاز المنهاج.

### 1.2 تخزين الحالة من جانب العميل (Client-side Persistence)
- تخزين التقدم الشخصي، الإشارات المرجعية (Bookmarks)، المسار المخصص (My Path)، القوالب المحفوظة، وإعدادات اللغة والسمة في الـ `localStorage`.

### 1.3 محاكيات المنظومة البصرية (Interactive Simulators)
- محاكي تنفيذ الوكلاء الفرعيين (Subagents Sandbox Simulator).
- محاكي خطافات دورة حياة التنفيذ (Hooks Execution Simulator).

---

## 🔴 2. ما يقع خارج النطاق (Out of Scope)

### 2.1 تشغيل الوكلاء الفعليين من الخادم (Execution Runtime Engine)
- المنصة لا تقوم بتشغيل أوامر bash حقيقية أو استدعاء وكلاء Claude Code الحقيقيين عبر واجهة برمجة التطبيقات على جهاز المستخدم؛ المحاكاة هي لأغراض تعليمية وإرشادية بصرية فقط.

### 2.2 الحسابات المركزية وقواعد البيانات السحابية (User Auth & Cloud DB)
- لا يتطلب التطبيق تسجيل دخول ولا يستخدم خادماً مركزياً لحفظ تقدم المستخدمين؛ كافة البيانات تحفظ في متصفح المستخدم فقط لضمان الخصوصية والسرعة والاستقلالية.

### 2.3 تحرير الشيفرة البرمجية للمشاريع الخارجية
- المنصة توفر قوالب وإرشادات ومولدات، ولكنها ليست بيئة تطوير متكاملة (IDE) لتعديل ملفات كود خارجية مباشرة.

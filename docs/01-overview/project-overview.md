# نظرة عامة على المشروع | Project Overview

## 1. التعريف بالمشروع (What is Claude Atlas?)
**أطلس كلود (Claude Atlas)** هو تطبيق ويب تفاعلي عالي الأداء مبني باستخدام **React 19** و **TypeScript** و **Tailwind CSS v4**، يعمل كخريطة معمارية بصرية وموسوعة معرفية تطبيقية لمنظومة **Claude Code** التابعة لشركة Anthropic.

تم ابتكار المنصة لتحويل المفاهيم المعقدة، مثل:
- ملفات التوجيه التأسيسية (`CLAUDE.md`)
- بروتوكول السياق النموذجي (MCP - Model Context Protocol)
- الذاكرة التراكمية وسياق المشاريع (Project Memory)
- خطافات دورة حياة التنفيذ (Lifecycle Hooks)
- الوكلاء الفرعيين (Subagents)
- المهارات التوسعية (`SKILL.md`)

من مجرد ملفات نصية جافة إلى بيئة تعليمية واستكشافية بصرية متكاملة تمكّن المهندسين من استيعاب المنظومة وتطبيقها بإنتاجية فائقة.

---

## 2. المشكلة التي يعالجها المشروع (Problem Statement)
مع التطور السريع لأدوات الوكلاء البرمجية وتحديداً منظومة Claude Code، يواجه المطورون والفرق الهندسية عدة تحديات:
1. **تشتت المفاهيم**: صعوبة التمييز بين الأدوار المختلفة لمكونات المنظومة (مثل متى نستخدم Skill مقابل Subagent، أو الفرق بين الذاكرة التراكمية وملف الدستور `CLAUDE.md`).
2. **غياب المحاكاة التفاعلية**: يفتقر التوثيق التقليدي إلى إمكانية تجربة السيناريوهات البرمجية ومحاكاة دورة حياة تنفيذ الوكلاء أو تسلسل الـ Hooks بصرياً قبل كتابتها.
3. **صعوبة إنشاء القوالب الصحيحة**: يستهلك المهندسون وقتاً في صياغة هياكل ملفات `CLAUDE.md` وقواعد المهارات من الصفر دون أمثلة معيارية مثبتة ومعتمدة معمارياً.
4. **الحاجة لمحتوى عربي تقني رصين**: شح المراجع العربية العميقة الموجهة لمهندسي الذكاء الاصطناعي والتي تحافظ على المصطلحات الدقيقة وتقدم شروحاً بيداغوجية موحدة.

---

## 3. القيمة المضافة والحل (The Solution)
يقدم أطلس كلود حلاً معمارياً متكاملاً يتضمن:
- **خريطة معمارية تفاعلية (Interactive Architecture Map)**: تعرض ترابط المفاهيم والعقد المعمارية مع فلاتر حسب المستوى والمسار.
- **النموذج البيداغوجي المعياري ذو الـ 14 نقطة**: هيكل تعليمي صارم لكل مفهوم يغطي التعريف، آلية العمل، متى يُستخدم ومتى يُتجنب، الأمثلة المضادة، والتمارين التفاعلية.
- **محاكيات تفاعلية حية (Interactive Simulators)**: محاكاة فورية لآلية عزل الوكلاء الفرعيين وتدفق الخطافات البرمجية.
- **مختبر الأوامر ومولدات القوالب (Generators & Prompt Lab)**: توليد ملفات الإعدادات والذاكرة التأسيسية بنقرة زر وبأعلى المعايير.
- **نظام متابعة التقدم الشخصي (My Path & Progress)**: حفظ العقد في مسار تعليمي مخصص وتتبع الإنجاز عبر التخزين المحلي للمتصفح.

---

## 4. الفئات المستهدفة للمستخدمين (Target Users)
- **مهندسو ومطورو البرمجيات (Software Engineers)**: الراغبون في تعظيم كفاءة استغلال Claude Code أثناء التطوير اليومي.
- **معماريو الأنظمة (Solution Architects)**: الباحثون عن وضع معايير حوكمة وتوحيد لمشاريع فرقهم عبر ملفات `CLAUDE.md` والـ Subagents.
- **مهندسو التوجيه والذكاء الاصطناعي (AI & Prompt Engineers)**: المتخصصون في تصميم أدوات وسياقات الوكلاء المستقلين.
- **المتعلمون والمساهمون الجدد (Students & Tech Learners)**: الراغبون في بناء فهم عميق وسليم لمنظومات الذكاء الاصطناعي الحديثة.

---

## 5. التقنيات الجوهرية للمشروع (Core Tech Stack)
- **مكتبة الواجهة**: React 19 (`react`, `react-dom`)
- **لغة البرمجة**: TypeScript 5.8+
- **بيئة التجميع وخادم التطوير**: Vite 6
- **التصميم والتنسيق**: Tailwind CSS v4
- **المكتبات الحركية والأيقونات**: `motion` (Framer Motion v12) و `lucide-react`
- **نمط التطبيق**: Single-Page Application (SPA) بدون خادم خلفي معتمد على العميل بالكامل (Client-side Only).
